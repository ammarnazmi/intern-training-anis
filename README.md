# LAB Stack Boilerplate

Laravel-Alpine.js-Bootstrap stack boilerplate.

## Tech stack

- Laravel 13
- Alpine.js 3
- Bootstrap 5

The acronym for this tech stack will be **LAB stack**, based on the first character of **L**aravel, **A**lpine.js and **B**ootstrap.

## How to run the project?

- Clone the repository
- Create `.env` file, based on `.env.example` file
- Run `composer install`
- Run `npm install`
- Run `npm run dev`
- Run `php artisan migrate`
- Run `php artisan db:seed`
- Serve the project through a web server
